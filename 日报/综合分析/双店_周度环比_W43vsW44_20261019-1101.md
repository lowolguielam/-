# 双店周度环比：W43（10-19~10-25）→ W44（10-26~11-01）

**一句话**
🔴 **大世界 GMV +74.6% 不是"生意变好了"，是两笔钱搬进来的**：补差链接 ¥9,294.58 + ITOBORI 一笔 ¥22,500，两者合计 ¥31,795，等于本周 GMV 全部增量（+¥31,593）。**剔掉这两项，常规商品 ¥42,145 vs 上周 ¥42,346，−0.5%，横着走。** 🟢 **真正改善的是退款**：同口径退款率 23.69% → 8.34%（−15.4pp），净收入 ¥31,273 → ¥63,546（+103%），现金流是真的。🟡 **同同 GMV +260.6% 但依然只有 5 个买家**，且上周那个"0 退款"是假的——W44 退了 ¥1,138 属于 W43 的单。

## 零、先讲清三条口径（不看这三条会读错）

   W44 有 4 个"百件级"链接，件数 100–102、单价 ¥0.6–¥49.9——不是商品，是**补差/差价链接**：

   它们带来 404 件、8 个买家。**W43 没有任何这类链接**。所以直接比"件数 71→476"、"加购 225→1,033"、"买家 49→55"都会被放大，本报告一律给「原始」和「剔补差」两套数。

2. **退款按"退款发生日"统计，不按下单日**
   W44 有 ¥2,432.26 的退款对应 0 支付件的商品（FootJoy FJ Fuel ¥1,818.26、TaylorMade TP5 ¥527、MELELINKS ¥87）——**这些是上周或更早的单在本周退**。同同更明显：W44 退了 Bushnell 收纳包 ¥293（正好是 W43 卖的那一单）、GFORE 手套 ¥552。**单看一周的退款率都会失真。**

3. **W43 是双 11 预售周，"下单"远大于"支付"**
   大世界 W43 下单 ¥122,037 / 支付 ¥42,346（**支付率 34.7%**）；W44 下单 ¥79,196 / 支付 ¥73,940（**支付率 93.4%**）。这大概率是预售定金与尾款的时间差，不是需求差异——**两周 GMV 对比必须带上这层背景**（未经订单级验证，标为推断）。

## 八、结论：三条要改的

1. **大世界先别庆祝 GMV**。常规盘横在 ¥42,000 两周了，W44 的"翻倍"是补差 + 一笔大单。**下一步该看的是：把 ITOBORI 这类 ¥2 万级大单从"偶发"变成"可复制"**（它是靠主动回访/消息成交的，不是靠广告），以及**Garmin 三款 874 访客零成交的问题（两周未解决）**。
2. **同同的唯一问题是流量，不是定价也不是履约**。转化率 1.63% 是三周最高、搜索 190 访客还能出 3 单，说明店本身没坏。**推荐归零 + 站外 91 访客 0 成交**是两条要立刻查的线。
3. **口径要立规矩**：补差链接单独标记、退款看三周滚动、GMV 一律同时给"账面/同口径"两个数。否则每周都会得出相反的结论（本周就是活例）。
